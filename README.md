# Analisador com Interface Melhorada - Cartola FC

Este projeto exibe uma interface interativa com:
- Status dos jogadores
- Adversário da rodada
- Mando de campo (Casa/Fora)
- Sugestão de time apenas com jogadores prováveis

## Instalação
```bash
pip install -r requirements.txt
```

## Execução
```bash
streamlit run cartola_interface.py
```
